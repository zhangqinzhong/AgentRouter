记忆页内嵌 [ai-memory](https://github.com/akitaonrails/ai-memory) v2.5.2 运行时，把项目知识库、会话采集、任务交接和客户端接入整合成原生页面。它不内嵌上游的 web 界面；上游源码、许可证与版本溯源见仓库 `vendor/ai-memory` 与 `vendor/ai-memory.UPSTREAM.md`。

## 启用与生命周期

记忆默认**不开启**。首次启动时，应用把内置（校验过校验和的）运行时复制到只读运行目录、初始化数据目录并启动服务；运行时随应用打包，没有应用内下载或单独安装步骤。

| 行为 | 说明 |
| --- | --- |
| 数据目录 | `<AgentRouter 配置目录>/ai-memory`（macOS/Linux 默认 `~/.agentrouter/ai-memory`），知识库、SQLite、原始事件、配置与备份相互独立，不混入工作空间和档案目录。 |
| 网络边界 | 服务只监听 `127.0.0.1:49374`，请求需要应用持有的本地随机凭据（不进渲染进程）。 |
| 端口冲突 | 49374 已被占用时视为冲突，不会接管或停止其它进程。 |
| 生命周期 | 关闭窗口不停止记忆服务，退出应用才停止；`自动启动` 可在设置中开启。 |
| 状态 | 页面顶部显示 `已停止 / 启动中 / 运行中 / 停止中 / 运行异常 / 暂不可用`。 |

## 页面分区

| 分区 | 内容 |
| --- | --- |
| 知识库 | 按项目浏览记忆页面，安全的 Markdown 阅读，新建、编辑、固定保留。 |
| 检索 | 项目内或跨项目检索。 |
| 会话 | 分页查看已采集的会话事件明细。 |
| 交接 | 任务交接摘要、状态与后续步骤；含所有者脱敏处理。 |
| 客户端 | 预览、安装、检查、移除各客户端的全局 MCP / Hook 接入。 |
| 维护 | 完整的上游 MCP 工具目录，按 schema 生成原生表单，也支持结构化参数模式；**非只读调用需要确认**。 |
| 设置 | 生命周期（启动 / 自动启动）、语义检索、备份、完整上游 TOML 配置与有界日志。 |

## 客户端接入

客户端页覆盖二十种客户端 / 引擎变体，包括 Claude Code、Codex、OpenCode 1/2、Cursor、Gemini、Grok、Pi、OMP、Command Code、Antigravity、Zero、ZCode、Devin、Kimi、Kiro 2/3、Zed、Muse 和 macOS Claude Desktop，各自的能力差异会如实展示。

接入流程是 `预览 → 安装 → 检查`，移除前先预览：

- 安装会复用上游的合并逻辑，并记录修改前的文件内容和安装后的精确快照（仅所有者可读）。
- 移除时只有当前文件内容与安装快照一致才还原前像；如果期间被其它工具或用户改过，移除会**拒绝执行**而不是覆盖。
- 共享同一配置文件的客户端可能需要按安装的相反顺序移除。
- 移除客户端不会删除已存储的记忆。

项目级适配器（VS Code Copilot、Swival、Kiro v2 自定义 agent 钩子）需要显式指定目标，保留在内置 CLI 中，不做静默猜测。已配置的接入项不等于已验证的实时采集。

## 采集机制

采集严格按项目 opt-in：在愿意参与的项目里放一个 `.ai-memory.toml`，显式写明 `workspace` 与 `project` 名称。AgentRouter 不会自动写标记文件，也不会对所有仓库开启采集。已安装集成的 Hook 会在本地缓冲事件，按会话边界和有界的中途冲刷交付给服务。

## 语义检索

语义检索默认关闭，避免隐式下载模型或外呼。开启时会先弹出确认，说明数据边界：

- 本地供应商（默认）：首次使用需下载一次模型，数据不出本机。
- 云端供应商：需在高级 TOML 配置中显式选择，**记忆内容会发送给该供应商**；保存配置同样会提示外部调用风险，变更在重启后生效。

继承的模型密钥、档案目录与任意 `AI_MEMORY_*` 环境变量都不会传给记忆服务；历史会话的自动回填默认关闭。

## 数据安全与备份

- 所有存储的记忆内容都视为不可信历史：渲染层不执行其中的 HTML，后端读取走封闭的路由白名单；普通记忆内容不自动等于当前分支的正确描述。
- `设置 → 备份` 可手动备份；保存 TOML 配置时也会保留私有备份。
- **升级前先做完整备份**：数据库迁移属于上游，换成旧版可执行文件不等于数据库回滚。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 状态一直是 `已停止` | 在页面顶部点 `启动记忆`；确认 49374 端口未被其它进程占用。 |
| 状态 `运行异常` 或 `暂不可用` | 到 `设置` 查看有界日志；端口冲突或运行时损坏都会在此体现。 |
| 检索没有结果 | 确认项目已通过 `.ai-memory.toml` opt-in 且已产生会话；语义检索未开启时只有基础检索。 |
| 客户端接入后没有采集 | 确认目标项目已 opt-in、客户端已重启；已配置的接入项不代表已验证的实时采集。 |
| 移除客户端被拒绝 | 配置文件在安装后被其它工具修改过；先核对差异再手动处理，记忆数据不受影响。 |
