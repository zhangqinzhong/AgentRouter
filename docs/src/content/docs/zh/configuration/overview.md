概览是固定布局的单页仪表盘，自上而下依次是时间范围与筛选、统计行、系统状态条、用量趋势、构成分析和账户余额。它不再支持编辑布局或增删组件；1.4.0 之前配置过的旧仪表盘布局会被忽略，无需手动清理。

## 适用场景

| 场景 | 看什么 |
| --- | --- |
| 检查网关是否正常 | 系统状态、成功率、错误数 |
| 估算今日或近期消耗 | 请求数、总令牌、估算成本 |
| 比较上游使用情况 | 供应商分析、模型构成、客户端分析 |
| 关注账户额度 | 账户余额、套餐额度、剩余额度、账户状态 |

## 时间范围与筛选

顶部的 `按时间查看用量` 控制统计行、趋势和构成分析的数据窗口。切换后，请求数、令牌、成本和分布会按新的窗口重新聚合。

| 选项 | 统计窗口 |
| --- | --- |
| `今天` | 当前本地日期从 00:00 到现在，按小时分桶。 |
| `24 小时` | 最近 24 小时，按小时分桶。 |
| `7 天` | 最近 7 天，按天分桶。 |
| `30 天` | 最近 30 天，按天分桶。 |
| `自定义` | 自行选择起止日期（含两端）。点击后在弹出的日期面板中选起止日期并 `应用`。 |

两处不受时间范围影响：

| 区块 | 行为 |
| --- | --- |
| 系统状态条 | 固定显示最近 90 天，见下文。 |
| 账户余额 | 展示供应商账户连接器最近一次获取到的快照。 |

时间范围下方是两个筛选器：`供应商` 只列出已启用的网关供应商，`模型` 的选项随所选供应商联动。筛选会同时作用于统计行、趋势和构成分析。

## 统计行

统计行展示当前时间范围与筛选下的四个指标：请求数、总令牌、估算成本和请求成功率。成功率下方附带错误数；请求数大于零时，统计行下方会再显示一条请求与成功率的摘要。

## 系统状态条

系统状态条固定显示最近 90 天，不随顶部时间范围切换。每个产生过用量的供应商一行，按天显示色块：正常、警告、错误和无请求对应不同颜色。悬停或键盘聚焦某个色块，可以查看当天的日期、请求数和错误数。

状态条默认停在最近的一天，行与行之间滚动同步，可以用两侧按钮向前翻页查看更早的记录，月份之间有分隔。标题行汇总 90 天窗口内的请求、成功率与错误。没有供应商数据时显示整体 `API Service` 一行。

## 用量趋势

用量趋势图跟随顶部时间范围：`今天` / `24 小时` 按小时展示，`7 天` / `30 天` / `自定义` 按天展示。悬停数据点可以查看当天的令牌、请求数、成本和按模型的明细。

## 构成分析

构成分析分为三节：`模型`、`客户端分析` 和 `供应商分析`。每节按令牌量排序，最多显示前 6 项，其余合并为 `其他`；节标题右侧显示该维度的令牌与成本合计。

每一行左侧是图标（供应商使用配置的图标，模型和客户端按品牌自动识别），中间是名称、请求数和占比条，右侧是令牌数和占比。悬停某一行会展开明细卡片，包含：

| 内容 | 说明 |
| --- | --- |
| 令牌与占比 | 该行令牌总量及在当前窗口内的占比。 |
| 请求数与成本 | 该行的请求数和估算成本。 |
| 输入 / 输出 / 缓存拆分 | 三类令牌的数量和各自占比，缓存占比可以用来判断缓存命中情况。 |

同一个模型经由不同供应商路由时会在底层产生多行，界面上会按显示名合并成一行再排序。

## 账户余额

账户余额区读取供应商配置里的账户 / 用量连接器。要让它显示余额或剩余额度，需要先在供应商配置中启用并测试 `获取用量`。每个账户一行，展示额度仪表和状态；顶部可整体刷新，未配置连接器时可跳转去配置。

如果账户余额为空，优先检查：

1. 供应商是否配置了账户 / 用量连接器。
2. `获取用量` 测试是否成功。
3. API Key 或账户接口是否仍有效。

## 重置统计

工具栏右侧的 `重置统计` 按钮会清空概览使用的用量事件，并弹出确认对话框。重置只影响概览统计，不会删除请求日志、供应商、账户连接器或任何配置，且删除后无法恢复。

## 数据来源与排障

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| 请求、令牌或成本为 0 | 当前时间范围或筛选下没有经过 AgentRouter 的请求，或用量捕获尚未记录。 | 切换到 `24 小时` / `7 天`，清空供应商 / 模型筛选，确认客户端请求确实走 AgentRouter。 |
| 成本显示为 `$0.00` | 模型没有价格信息，或用量过小。 | 检查模型目录和供应商模型名是否能匹配价格；低于 0.01 美元会显示更多小数。 |
| 成功率、错误数不符合预期 | 只统计 AgentRouter 捕获到的请求结果。 | 对照日志页面中的请求记录。 |
| 构成分析没有数据 | 用量记录里缺少模型、供应商或客户端信息。 | 确认请求经过 AgentRouter，并检查上游响应是否返回 token usage。 |
| 账户余额为空 | 没有账户连接器，或 `获取用量` 失败。 | 到供应商配置中测试账户 / 用量字段映射。 |
