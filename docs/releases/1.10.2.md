# AgentRouter 1.10.2

## 用量

- 近 30 天内又变长的 Codex 会话会补记后续用量。
- 带用量记录的 Antigravity 回合按实际 token 计费；没有这份记录的仍按文本估算。
- 补充 GPT-6.1 Sol、Cursor Composer 2.5、Gemini 4 Argon、Grok 4.6 和 Grok 4.7 的价格，包含 Fast 和 GPT-6.1 Sol 的长上下文加价。

## 会话

- CodeBuddy 的进度、用量和元数据记录不再重复计入消息 token。
- 刷新时，数据库时间没变也会重新读取。读不出来的 Copilot、Cursor 和 Hermes 数据库会保留已有会话。
- 左侧 Agent 和项目默认收起。

## 记忆

- 内置 ai-memory 3.0.0。已经在运行的记忆服务要等下次用这个版本启动才会更换；更换前请备份整个记忆目录。
- 客户端接入预览会标出将要写入的新内容，并可以收起。
- 接入 OpenCode 时写入 1.x 插件。OpenCode 2 使用自己的插件。

## 验证边界

用量、会话核心和记忆溯源测试已在本机通过。安装包以 GitHub Release 的 CI 结果为准。
