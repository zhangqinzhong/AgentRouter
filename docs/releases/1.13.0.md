# AgentRouter 1.13.0

## 新功能
- 用量支持按客户端和配置实例筛选，分别查看 Claude Code、Claude Official、CodexCompany 等来源。
- 概览页模型筛选作用于实际采集数据；更新概览布局及统一主题、控件和状态组件。
- 菜单栏和概览支持读取 Claude Official 本地订阅额度，按账户及组织匹配，不增加 Claude API 请求。
- 会话搜索增加中文、日文、韩文两字词索引；MiMo 支持子代理会话、导入历史识别和旧版数据库。

## 修复与性能
- 修复 WorkBuddy 未完整写入记录的漏采、ZCode providerId 识别和 DeepSeek Harness 分叉历史重复计数。
- Codex 模型归属按真实记录和配置实例保留，迁移历史数据时避免重复统计。
- 复用未变化的会话缓存；修复 Claude 会话标题和分支继承标题。
- Cursor、Grok Bot、Grok Build 在临时网络故障时保留有效额度快照，校验账户、产品、重置时间和刷新顺序。
- 更新 Grok、Gemini 模型价格及别名。
- ai-memory 从 3.2.5 升级至 3.4.5，包含上游安全与稳定性修复，并保留现有 MiMo 记忆触发规则。

## 升级说明
- 保留已有供应商、配置实例、自定义采集目录和本地数据。
- 首次启动会重建部分派生会话索引和缓存；记忆数据库由新版运行时迁移，回退前须恢复旧版数据备份。
