# AgentRouter 1.9.4

## 修复

- 概览统一使用本地会话采集用量，包含未经过网关的 Codex、Claude 等客户端；网关运行状态保持独立。
- 补齐 Codex 上下文压缩产生的用量，避免重复记录造成重复计数；更新已有采集缓存。
- 菜单栏与窗口趋势共用查询逻辑：日为过去 24 小时、周为过去 7 天、月为过去 30 天、总计包含全部历史。
- 概览的“今天”和“24 小时”使用各自的时间轴，跨天数据不会折叠到同一小时。

## 发布流程

- 新增 PR 源码及原生 macOS 检查，合并发布请求后自动创建 tag 并构建安装包。

滚动窗口保留边界聚合桶，时间精度受原始采集粒度限制。
macOS GitHub 安装包采用 ad-hoc 签名，未经过 Apple 公证。
