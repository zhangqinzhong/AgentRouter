# AgentRouter 1.14.0-rc.1

## 新功能
- Agent 配置档案中的系统默认 Claude Code / Codex 配置可一键“恢复原始设置”：先停用接管，再只还原 AgentRouter 写入的项目。
- 供应商可单独关闭“延迟加载工具”，兼容不接受 `defer_loading` 的上游。
- 配置档案会列出已不存在的已选模型，可直接移除。
- OpenAI 兼容的 `/v1/models` 返回推理能力信息。
- 新增 Z.ai、MiniMax 套餐额度显示。
- 主窗口默认以合适尺寸打开，不再全屏，并记住上次的大小和位置。

## 修复
- 网关请求失败时说明失败的供应商、模型和上游原因，并提示如何恢复出问题的系统默认配置。
- 流式响应在事件边界发送结束错误，上游流被截断时明确报错。
- 发往 OpenAI 官方 Responses 接口前清理可读推理历史，Codex 切换模型后不再因 400 中断会话。
- 保留供应商自有的 thinking 参数，按模型作者设置输出上限，跨协议保留 Anthropic `tool_result` 图片。
- 不再把客户端代理头和 cookie 转发到上游；`API_TIMEOUT_MS` 对网关子进程生效。
- 用量统计中每个请求只计一次结果，修复按供应商的用量序列。
- 配置档案模型选择保持一致，按凭证优先级路由，概览不再显示空模型。
- Docker 管理端限制来源、隐藏供应商密钥，容器服务以非 root 用户运行。
- Windows 上网关和 MCP 子进程不再弹出控制台窗口。

## 维护
- 更新 Claude Fable 5.2、GPT-6.2、Gemini 4、Muse Wonder 价格。
- 内置 ai-memory 升级至 3.5.0，桌面运行时升级至 Electron 42.11.18。

## 升级说明
- 保留已有供应商、配置档案和本地数据。
- ai-memory 3.5.0 首次启动会迁移记忆数据库（V107–V112）；升级前建议备份 `~/.agentrouter/ai-memory`，回退前须恢复该备份。
- 本版为候选版本，不进入稳定版自动更新源。
