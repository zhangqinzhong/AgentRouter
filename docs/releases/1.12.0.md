# AgentRouter 1.12.0

## 新增
- 设置增加「数据来源」，可添加、停用或移除 Claude Code、Codex 的额外数据目录。用量与会话共用目录配置，支持独立配置实例。
- 新增 Muse Code、OpenSquilla 用量采集，扩展 ZCode、OpenCode、Kimi 和 OMP 会话分析。
- 内置 ai-memory 升级至 3.2.5。

## 修复
- Windows 自定义采集目录与会话索引统一读取 AppData 配置；采集 worker 遵循运行环境的独立 home。
- OMP 升级补采不再遗漏新消息、新文件和未写完的记录，总量与项目统计保持独立游标。
- MiMo 临时读库失败保留完整缓存并重试；Kimi 官方会话读取正确的模型配置。
- 修复 Codex 压缩用量、时区筛选及会话费用计算，支持 `.zst`、`.zstd` 会话日志。
- 修复记忆服务升级后的版本校验。

移除采集目录不会删除客户端文件或已采集的历史用量。只有客户端保存在本地的用量记录可以被采集；普通桌面聊天未落地的 Token 数据不作推算。

## 构建
- 补齐 macOS 小组件的 XcodeGen 构建依赖，并在 PR 阶段执行小组件构建。
- 修复草稿版本的查询与恢复发布；已经验证的文件不会重复上传，校验失败会保持草稿。
