# AgentRouter 1.9.8

## 新功能

- 新增原生记忆管理页面，内置 ai-memory 2.5.2，支持项目知识库、客户端接入、会话记录和记忆交接。
- MiMo 自动采集已完成的对话轮次，后续对话自动读取，无需手动结束会话。

## 修复

- 概览和用量统计将 Grok Bot 与 Cursor 分开归类，历史记录同步生效，总量保持不变。
- macOS 桌面配置通过系统标准应用接口启动，保留代理环境、独立配置和进程管理。
- 修复网关收到非 JSON 错误响应时的异常处理。

## 升级说明

- 已使用开发版记忆功能的用户，升级记忆运行时前应备份完整记忆数据目录。
- macOS GitHub 安装包采用 ad-hoc 签名，未经过 Apple 公证。
