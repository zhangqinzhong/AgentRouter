# AgentRouter 1.12.1

## 修复
- 数据来源仅显示手动添加的目录，默认目录与配置档案目录继续自动采集。
- 调整目录列表、开关和移除操作；不存在的自定义目录保留提示，方便管理。
- 切换目录开关不再强制重建全部历史用量。
- 用量、趋势和热力图先显示已有数据，再更新采集结果；快速切换时间范围时不会被旧请求覆盖。

## 性能
- Codex 会话分析增加持久化聚合缓存，重启后复用未变化的记录；文件变化或缓存损坏时重新解析。
- 减少压缩会话的重复解码，将较慢的会话分析与常规统计查询分开处理。
- 避免未变化的聚合文件重复写入，缓存 macOS 用户资料读取结果。

首次建立会话分析缓存仍需要读取历史文件，后续加载可复用缓存。目录开关控制后续采集，不删除已经采集的历史数据。
