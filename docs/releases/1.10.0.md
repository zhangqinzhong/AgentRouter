# AgentRouter 1.10.0

## 会话工作台

- 在 AgentRouter 中统一浏览与搜索本机会话，阅读消息、思考、工具调用、图片和子代理分支。
- 支持收藏、置顶、导出、原客户端继续、活动统计、记忆文件、会话清理和 SSH 来源。
- 自带独立维护的会话解析核心、CLI 与可选 MCP/客户端插件，无需安装 Wake。感谢 Wake 作者 @iAmCorey 的 MIT 开源实现。
- 支持 24 类客户端来源，包括 MiMo；解析可用性取决于客户端是否保留可读取的本地记录。

## 修复

- 修正系统上下文显示、分支切换、收藏检索及记忆文件切换问题。
- Codex 档案中的旧默认供应商名称更新为 AgentRouter，保持原 provider ID 和自定义名称。
- 吸收 CCR #1871：Docker 未登录访问不再收到管理 token；修正以连字符开头的 token 导致启动失败。感谢 @mertkayacs。

## 使用说明

插件需要显式安装，SSH 来源需要自行配置。文件型会话清理移入废纸篓，共享数据库会话仅隐藏。Docker 用户需用自己配置的 token，或容器日志中自动生成的管理链接登录。

## 验证边界

本机验证以 macOS Apple Silicon 为主；真实 SSH、客户端插件安装和实际删除未在用户数据上执行。其余平台以 CI 结果为准。
