AgentRouter 首个独立版本，版本号从 1.0.0 开始。

- 统一应用及菜单栏图标，保留 AgentRouter 图标。
- 请求列表显示首 Token、输出速率、平均吞吐率及总耗时。
- 新增日志保存天数，自动清理过期记录、关联轨迹和正文文件。
- 修复日志正文替换、重复回放造成的文件残留。
- 合入上游凭据并发写入保护、配置数据库失败重试、跨协议限额估算和请求重试修复。
- 配置 AgentRouter 自己的 GitHub Releases 更新源。

本版本提供 macOS Apple Silicon（arm64）的 DMG 和 ZIP。Intel Mac、Windows 和 Linux 请使用 1.0.1 或更新版本。

macOS 包使用本地签名，暂未 Apple 公证。此版本的 macOS 自动安装尚未完成验证，可从 Releases 手动下载替换安装。此前标为 3.0.22 的本地开发版需手动安装本次 1.0.0；后续沿 1.x 递增。
