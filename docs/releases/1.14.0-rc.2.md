# AgentRouter 1.14.0-rc.2

## 新功能
- Codex 配置档案支持原生生图：在高级设置中开启后，可选择已配置的图片生成供应商和模型，用于生图和图片编辑。

## 修复
- 适配当前 ChatGPT.app 的目录结构，Codex app-server 重新通过 ChatGPT 自带的签名 Node 启动。
- Antigravity 2.34 移除 GetUnleashData 后，恢复额度读取。
- Grok Build 免费用量按零费用计算；Batch/Flex 档位和未固定版本的 Claude Mythos 别名不再套用标准价格。

## 维护
- 新增 qwen4-max、Claude Mythos 5.2、Gemini 4 Neon 价格。
- 内置 ai-memory 升级至 3.6.2。

## 升级说明
- 保留已有供应商、配置档案和本地数据。
- ai-memory 3.6.2 首次启动会迁移记忆数据库（V113–V115）；升级前建议备份 `~/.agentrouter/ai-memory`，回退前须恢复该备份。
- 本版为候选版本，不进入稳定版自动更新源。
