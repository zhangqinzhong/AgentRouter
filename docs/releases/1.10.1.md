# AgentRouter 1.10.1

## 会话阅读

- 会话页只保留检索和阅读。有会话的 Agent 和项目在左侧主导航展开，点选后收窄列表。
- 打开会话时落在最新消息。搜索命中仍从对应消息开始。
- Codex 记忆引用显示说明、文件行号和来源会话，不再把引用标签原文留在正文里。
- 活动统计、记忆文件、清理和 SSH 不出现在会话页。这些能力仍留在会话引擎里。

## 记忆

- 记忆的 MCP 和 hooks 可以安装到 AgentRouter 管理的 Claude、Codex 配置档案。
- 管理服务在不启动网关时，复用已经运行的记忆服务。

## 验证边界

会话页和布局测试已在本机通过。安装包以 GitHub Release 的 CI 结果为准。
