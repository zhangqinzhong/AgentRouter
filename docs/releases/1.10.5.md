# AgentRouter 1.10.5

## 概览与监控

- 重构概览页：用量趋势、模型花费、客户端活动、账户余额和紧凑网关状态。
- 新增完整监控中心：时区、滚动时间范围、自动刷新、全页筛选、实时流量、成功率、耗时分布、失败详情、模型性能、渠道健康、调用方排行、流量流向和活跃时段。
- 切换统计范围保留图表，后台更新数据；快速连续切换合并请求，刷新保留时间滑块范围。
- P95、首字 P50 趋势与卡片指标一致，缺少请求或有效样本的时间段明确标注。

## 采集与记忆

- 吸收 TokenTracker 的 Codex 压缩会话采集、归档与活动记录去重、Grok 共享额度归类和 OpenCode 免费模型计价修复。
- 内置 ai-memory 升级至 3.1.2。记忆数据库升级前应备份完整记忆目录，已运行的服务在重启前仍保持当前版本。
- 保留 1.10.4 的小米 MiMo v2.6 模型迁移。

## 数据口径

监控中心统计经过网关的请求；本地客户端会话用量在概览和用量页展示。历史首字时间与流式信息受日志保留期限制，不会用零或插值补造缺失样本。

## 验证

通过核心、UI、类型检查以及真实 SQLite 请求数据交叉核对；对照多个时间范围和时区验证请求、Token、失败数和耗时分位数，并在 Chrome 实测筛选、刷新和图表交互。最终跨平台构建结果以本次 Release 工作流为准。
