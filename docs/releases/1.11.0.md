# AgentRouter 1.11.0

## 供应商模型整理记忆

- 在「模型整理」中直接选择 AgentRouter 已配置的供应商模型，通过本机网关提炼会话中的长期经验。
- 首次保存自动创建专用 API Key「AI Memory」，监控中心单独统计 ai-memory 用量；删除该 Key 后不会自动重建。
- 保留自定义 OpenAI 兼容 API，切换模型来源或地址时不沿用原有密钥。
- 支持将模型提出的记忆修改先放入待审列表，批准后写入。

## 客户端接入

- 内置运行时升级后，自动刷新仍由 AgentRouter 管理且未被手动修改的 Hook 接入。
- 保留手动修改过的客户端配置。
