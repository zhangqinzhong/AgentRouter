# AgentRouter 1.7.0

## 页面与设置

- 在 **设置 → 通用 → 默认时间范围** 分别设置概览、用量、会话、趋势的初始范围，自动保存，下次进入页面时生效。
- 概览和用量默认展示今天，会话默认展示近 7 天，趋势默认展示本月。
- 概览日期切换恢复到右上角，四项统计首尾贴齐内容区域、间距均匀，不再居中。
- 去除设置分类下重复的标题和图标。
- 热力图保留原有 53 周、小格子、配色和累计统计；宽度不足时自然横向滚动，不增加时间筛选、强制撑宽或自动补载空白历史。

## 供应商与请求日志

- 新增 OpenCode Go 的本地凭据识别、模型发现、会话请求头及官方账户用量支持。
- 新增和编辑供应商时，模型候选列表按协议筛选；已有配置和手填模型保留。
- 请求日志优先使用有效测速样本，展开详情可查看响应头、首文本、输出窗口、输出间隔和样本状态。
- 无效或不完整样本不显示误导性速率；没有新测速数据的旧日志保留原估算方式。
- 更新内置模型目录至 4,732 个模型，不改变已配置的模型选择。

## 稳定性与性能

- 修正路由别名计费、模型回退请求头及 DeepSeek/OpenCode 缓存 Token 统计。
- 网关错误包含实际失败原因，改善上下文超限和认证配置冲突处理。
- 网关配置确认默认等待 30 秒，支持环境变量调整。
- 修复流式连接取消和上游断流时的资源释放。
- 概览等待配置就绪后再取数，慢查询不会触发重叠轮询；会话按所选日期窗口请求。
- 补齐 CLI `--daemon`、Docker 日志正文 worker、Windows 转义及 TypeScript 构建兼容性。
