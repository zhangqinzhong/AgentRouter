# AgentRouter 1.9.11

## 会话详情

- 会话列表新增详情面板，查看模型用量、Token 构成、费用来源和估算性能。
- 区分免费模型与缺少定价的模型，费用不完整时显示下限标记。
- 保留客户端筛选、子会话展开和继续会话；修复详情标签翻译及数字换行。

## 网关与采集修复

- 修复上游流中断处理，完善响应头日志、Codex 会话亲和性和按协议选择模型。
- 修复 OpenRouter 模型目录超时及自定义模型列表地址处理。
- 修复 Claude 分叉会话去重、OpenCode 指纹归属、Grok 额度回退、Kimi 凭据识别及 Claude 账户额度缓存匹配。

首次打开会话页会重建本地统计缓存，可能比后续打开耗时更长。估算速度来自本地会话时间戳，不代表纯生成速度。工具调用等部分活动指标目前仅支持 Grok。

macOS GitHub 安装包采用 ad-hoc 签名，未经过 Apple 公证。
