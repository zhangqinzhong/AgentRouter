## AgentRouter 1.5.0

- Refreshed the management UI across providers, agent profiles, settings, routing, logs and observability.
- Provider and agent profile editing stays in focused dialogs with a single checkable model list.
- Allowed-model counts now reflect the models currently available from each provider.
- Request logs and observability use full-width responsive layouts for dense operational data.
- Automatic model refresh no longer leaves stale provider models in agent profile allowlists.
